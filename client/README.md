# 📸 Instagram Clone

A full-stack Instagram clone built with **React**, **Node.js**, **Express**, and **Multer**.

## ✨ Features
- 📤 Upload photos and videos
- ❤️ Like, 💬 comment, 🔖 save posts
- 👤 Multiple profiles with creation
- 🧭 Explore page
- 📱 Full profile pages
- 💾 Posts persist to disk

## 🛠️ Tech Stack
**Frontend:** React, React Router, Axios, CSS
**Backend:** Node.js, Express, Multer, CORS

## 🚀 Run Locally
### Backend
cd server && npm install && npm start

### Frontend (new terminal)
cd client && npm install && npm start
